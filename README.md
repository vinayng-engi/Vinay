# Visual Dice Roller Simulator

A beginner-friendly data visualization tool built using **GNU Octave**. This project simulates rolling a six-sided die a custom number of times, calculates the exact percentage distribution for each face, and tracks the results using an interactive graphical bar chart.

## 🚀 Features
* Custom user input for the total number of dice rolls.
* Cleans up background graphics engine warnings automatically.
* Real-time calculation of statistical distribution percentages.
* Automatic generation of a custom styled bar chart plotting probability distribution.

## 🛠️ Requirements & Setup
* **Editor:** VS Code
* **Environment:** GNU Octave (Version 11.3.0 or newer recommended)

To run the simulator locally, navigate to this project directory in your Command Prompt and execute:
```cmd
"C:\Program Files\GNU Octave\Octave-11.3.0\mingw64\bin\octave.exe" --no-gui dice_sim.m
```
